# Project 3: SQL Data Analysis

## Objective
Analyze an orders dataset using SQL to extract meaningful business insights.

## Tasks Performed
- Retrieved data using SELECT
- Filtered records using WHERE
- Sorted data using ORDER BY
- Grouped records using GROUP BY
- Calculated COUNT, SUM, and AVG

## Tools Used
- SQLite
- DB Browser for SQLite

## Skills Learned
- SQL Fundamentals
- Data Querying
- Data Aggregation
- Business Data Analysis
